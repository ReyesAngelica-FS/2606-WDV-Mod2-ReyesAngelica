# StitchFlow Studio

## Overview

StitchFlow Studio is a real-time embroidery production management system inspired by my custom embroidery and design business, Ala Rey Studios.

The application synchronizes information across three connected interfaces:

- Mobile Operator Controls
- Tablet Production Dashboard
- Web Administration Panel

Using Socket.IO and TypeScript, all devices remain synchronized in real time, allowing embroidery operators, production supervisors, and business owners to collaborate efficiently.
